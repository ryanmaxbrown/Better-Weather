# NWS Weather Dashboard

A clean, mobile-first weather app powered by the National Weather Service API. Designed to be added to your phone's home screen as a PWA.

## Features
- 48-hour hourly forecast with sparkline charts
- 7-day day/night forecast
- Active weather alerts
- GPS geolocation or manual coordinates
- Remembers your last location
- Works offline (app shell cached)

## Setup on GitHub Pages

1. Create a new repository on GitHub
2. Upload all files from this folder
3. Go to **Settings → Pages → Source → Deploy from a branch → main → / (root)**
4. Your app will be live at `https://yourusername.github.io/reponame`
5. Open that URL on your phone and add to home screen

## Data Source
All forecast data comes directly from [api.weather.gov](https://api.weather.gov) — the official NWS API. Free, no API key required, US locations only.
